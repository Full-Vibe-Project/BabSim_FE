# 헬스케어 식단 관리 서비스 — PRD (Product Requirements Document)

> 버전: v0.1  
> 문서 소유자: FE 팀 (테스트 담당: @heesu01)  
> 최종 목표: AI 기반 자동 식단 기록/영양 분석/맞춤 추천으로 건강 관리 효율 최대화

---

## 1. 프로젝트 개요 (Overview)

- **프로젝트명**: 헬스케어 식단 관리 서비스
- **핵심 가치 제안 (Value Proposition)**
  - 사진 한 장으로 **자동 기록**, 개인 프로필과 질병 정보를 바탕으로 **맞춤 분석/추천**, Notion에 **자동 보관**
- **타겟 사용자**
  - 건강한 식습관을 만들고자 하는 일반 사용자
  - **질병 관리가 필요한 사용자**(예: 당뇨, 고혈압)
- **문제 정의**
  - 기록이 **번거롭고 지속하기 어렵다** → 습관화 실패
  - 기존 앱은 **칼로리 계산 중심** → 질병/개인화 한계
  - 데이터는 쌓이지만 **활용도가 낮고** 장기 리스크 분석 미흡
- **솔루션**
  - AI 이미지 인식 + 식약처 영양 DB로 **자동 기록**
  - 개인 프로필 + 최근 식단 기반 **영양 분석/맞춤 추천**
  - **Notion 자동 연동**으로 기록/리포트 자산화

## 3. 경쟁 분석 (Competitive Landscape)

- **밀리그램**: 기록/공유 강점, **수동 입력 비중 큼**
- **다이어트 카메라**: 칼로리 계산 정확도, **행동 변화 유도 부족**
- **다이어트 신/인아웃**: 다이어트 중심, **질환 맞춤 부족**
- **Unimeal/그레이팅/맞춤 식단몰**: 추천/구독 강점, **개인 장기 데이터 축적/분석 약함**

**우리의 차별점**

- AI 자동 인식 + **질병 맞춤 가이드**
- 장기 데이터 기반 **건강 리스크 알림**
- **Notion 자동 연동**으로 기록/리포트 자산화

---

## 4. 범위 (Scope)

### 4.1 포함 (MVP)

- 회원가입/로그인, 프로필/건강정보 입력
- 사진 업로드 + 음식 자동 인식 + 수기 보정
- 일/주/월 **영양 분석** 및 **요약 리포트**
- 부족/과잉 영양소 기반 **메뉴 추천**
- **Notion 연동**(기록/리포트 자동 저장)

### 4.2 제외 (Non-Goals / Post-MVP)

- 실시간 혈당/혈압 기기 연동
- 식단 구독/커머스
- 고도화된 예측 모델(의료 자문 포함)

---

## 5. 사용자 흐름 (User Flow)

1. 온보딩 → 프로필/질병/목표 입력
2. 메인 대시보드(오늘 현황/추천/퀵 기록)
3. **식단 기록**(사진 업로드 → AI 인식 → 보정/저장)
4. 분석 탭(일/주/월 리포트) → Notion 내보내기
5. 추천 탭(부족 영양소 기반 메뉴/레시피/외식)

> 와이어프레임/디자인은 Figma 링크로 관리 (팀 공유 링크 첨부 예정).

## 7. 수용 기준 (Acceptance Criteria)

### F-01 회원가입/로그인

- [AC-1] 이메일/비밀번호 유효성 검증(이메일 형식, PW≥8자)
- [AC-2] 성공 시 `/dashboard`로 이동, 실패 시 원인 메시지
- [AC-3] 새로고침 후에도 세션 유지(만료 시 자동 로그아웃)

### F-02 AI 식단 기록

- [AC-1] 사진 업로드 시 3초 내 로딩 UI 표시
- [AC-2] 인식 결과에 **음식명/용량/칼로리/주요 영양소** 포함
- [AC-3] 사용자 보정(수정/추가/삭제) 후 저장 가능
- [AC-4] 아침/점심/저녁/간식 구분 저장
- [AC-5] 저장 성공 시 해당 일자 타임라인에 반영

### F-03 주간/월간 요약

- [AC-1] 기간 선택(week/month) 시 차트 갱신
- [AC-2] **목표 대비 과다/부족** 항목 강조
- [AC-3] 요약 문장 자동 생성(한글 2~4문장)

### F-04 메뉴 추천

- [AC-1] 최근 7일 데이터 + 프로필 기준 추천 목록 노출
- [AC-2] 각 메뉴 카드에 **영양 요약/주의 질환** 표시
- [AC-3] 사용자가 “저장/관심” 시 재추천 로직 반영(선호 학습)

### F-05 Notion MCP 기록

- [AC-1] 최초 1회 Notion 토큰/DB 연결 설정
- [AC-2] 일일 기록 저장 트리거(수동 또는 하루 1회 자동)
- [AC-3] 실패 시 재시도 버튼과 원인 로그 제공

## 8. 비기능 요구사항 (NFR)

- **성능**: 식단 인식 API 왕복 ≤ 2.5s p75, 대시보드 FCP ≤ 2s
- **가용성**: 핵심 기능 99.5%/월
- **접근성**: WCAG AA 지표 준수(키보드 내비게이션/명도)
- **보안/개인정보**: 토큰 안전 저장, 민감 정보 최소 수집/암호화
- **i18n**: 한글 우선, 영문 준비(문자열 분리)

---

## 9. 데이터/모델

- **프로필**: 기본 정보(나이/성별/키/체중), 질병/알레르기, 목표
- **식단 항목**: 날짜/시간대, 음식명, 용량, 칼로리, 영양소(탄/단/지/당/나트륨 등)
- **외부 데이터**: 식약처 영양 DB, 국민건강 통계(분석 레퍼런스)
- **AI 인식**: 이미지 → 음식명/용량 후보, 신뢰도(score)
- **추천**: 부족/과잉 영양소 기반 규칙 + 휴리스틱

---

## 10. 외부 연동 (Integrations)

- **식약처 영양 DB**: 음식 영양 성분 매핑
- **Notion API**: 일일 기록/리포트 저장
- **(선택) 건강검진 결과 API**: 프로필 보강
